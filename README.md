# DiveIntoDeepLearning

Personal Jupyter notebook study notes and exercise solutions for several books.  
This repository is a learning log: it collects notes, code experiments, and selected exercise work in a structured way.

## Why This Name?

The repository name **DiveIntoDeepLearning** comes from its origin: it started as a place to record notes while reading *Dive into Deep Learning* (d2l). The title works on two levels:

- It refers to the AI field of **deep learning**.
- It can also be read literally as **learning deeply** — a more general idea.
- The phrase **“dive into”** captures an ideal state of learning: immersive, curious, focused, and persistent.

Because of this broader meaning, the repository has grown from a single-book notebook collection into a general-purpose study-notes repository.
